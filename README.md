# 日常集 · 生活工作台

> 单文件、零依赖、离线可用的个人生活管理工作台。
> 财务追踪、习惯打卡、健康管理、日程规划、待买清单、影音记录，全部收进一个 HTML 文件。

## 功能模块

| 模块 | 说明 |
|------|------|
| 财务追踪 | 支出记录、分类统计、月度预算 |
| 习惯打卡 | 每日习惯追踪、连续天数统计 |
| 健康管理 | 睡眠记录、体重趋势、健康提醒 |
| 日程规划 | 待办事项、周计划、日历视图 |
| 待买清单 | 购物清单、价格追踪、购买记录 |
| 影音记录 | 观影/阅读记录、评分、心得 |

## 技术特点

- 单文件 HTML（内联 CSS/JS），零依赖
- 数据存储在浏览器 localStorage
- 响应式设计，支持移动端
- 离线可用

## 使用方法

1. 下载 
2. 用浏览器打开即可
3. 数据自动保存在浏览器中

## 数据与隐私

- 所有数据保存在本机浏览器
- 不上传云端、不跨设备同步
- 换设备/清缓存会丢失数据，请定期导出备份
